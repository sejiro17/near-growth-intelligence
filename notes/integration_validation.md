## One offline command

```bash
.venv/bin/python -B analysis/44_rebuild_integrated_research.py --check
```

Use the installed Python environment described in the README. The command blocks
network operations and subprocess launch, invokes no collection functions and
verifies existing outputs byte-for-byte. Without `--check`, missing named
generated outputs use exclusive creation; existing files are never overwritten.
